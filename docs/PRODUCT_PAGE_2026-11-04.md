# Карточка товара: 4 ноября 2026

Изменения подготовлены локально; публикация не выполнена. Полный отчёт, проверки,
скриншоты и предложения по данным находятся в соседнем backend-репозитории:
[отчёт](../../SKUFnya/docs/product-page/2026-11-04/REPORT.md).

Сводка под ценой использует текущий вариант, `Product.material`, `heightMm`,
`sizeLabel` и `leadTimeDays`. Размер варианта имеет приоритет над общей высотой.
Масштаб и высота показываются вместе только при отсутствии разных размеров
в вариантах. Нулевой/неизвестный срок не означает готовность к отправке.

Необязательные общие для всех вариантов факты приходят через разрешённый
`attributes.purchaseInfo`: `assembly` (UNASSEMBLED / ASSEMBLED / BY_AGREEMENT),
`contentsUk`, `contentsEn` (до 600 символов). Редактирование реализовано в текущей
админке. Пустые значения показывают согласование перед оплатой; EN-комплектация
не подменяется выдуманным переводом и не меняет SEO-готовность карточки.

Обращение формируется локально, открывает черновик @SKUFnya_ua и позволяет
скопировать сообщение. Отправку выполняет покупатель. Выбор варианта/цвета
сохраняется в sessionStorage текущей вкладки с проверкой допустимых значений.

Цена, варианты, материал и purchaseInfo остаются данными сборочного снимка.
После редакционных изменений требуется существующая ручная сборка/публикация
Pages. Наличие цветов обновляется прежним механизмом; серверный quote остаётся
источником цены при оформлении.

Новая браузерная регрессия использует только локальный Pages-export и snapshot:

```bash
python3 -m http.server 54339 --bind 127.0.0.1 --directory apps/storefront/out
cd apps/storefront
SMOKE_BASE=http://127.0.0.1:54339 \
SMOKE_SNAPSHOT="$PWD/.next/cache/skufnya-build/catalog-snapshot.json" \
SMOKE_OUTPUT=/tmp/skuf-product-browser \
node --experimental-strip-types test/browser-product-purchase.mjs
```

Нужны Node 22, установленный Playwright Chromium и снимок с демонстрационным
Juggernaut, товаром с несколькими размерами и товаром с заполненным сроком.
API-запросы подменяются, реальные заказы не создаются. Для Firefox укажите
`SMOKE_BROWSER=firefox`; при другой версии установки — `SMOKE_EXECUTABLE`.

Остальные проверки: `pnpm typecheck`, `pnpm lint`, `pnpm test`, обычная
Pages-сборка и существующие export/XML guards (см. [TESTING.md](TESTING.md)).
Нативные клиенты Telegram на Android/iOS требуют отдельной приёмки на устройствах.
