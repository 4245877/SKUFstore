# Оформление и локализация недоступного каталога

Дата: 10 октября 2026 года.

## Результат

`CatalogLoadError` использует действующие `useI18n`, `LocaleProvider` и словари `uk`/`en`. Язык определяется маршрутом: украинские страницы без префикса, английские — `/en/`. Переведены заголовки, пояснения, подсказки, кнопка, состояние повторного запроса, скрытый статус для экранного диктора и дополнительное уведомление о недоступных категориях на главной. `lang` секции соответствует языку страницы. Переключатель языка сохраняет параметры и фрагмент URL по существующим правилам.

Текст сокращён: убраны повторяющиеся извинения, заверения о работе магазина и обещание восстановления. Возможные перебои описаны предположительно. Срок восстановления не указан.

## Визуальные решения

Композиция стала открытой: вместо замкнутой рамки, тени и розового фона используются белая поверхность и тонкие линии сверху и снизу. Контраст белого фона, чёрно-белой иллюстрации и тёмной кнопки, аккуратная окантовка и короткий розовый штрих перед надписью передают сдержанную ассоциацию с формой горничной. Буквальные украшения не добавлены; волнистый разделитель убран.

Сохранены Playfair Display, Manrope, имеющаяся палитра, радиус и токены кнопок. Заголовок — 24–32 px, основное сообщение — 15 px, пояснение — 14 px. Текст ограничен шириной 52ch, заголовок использует сбалансированные переносы. Видимый статус, повторявший сообщение, скрыт визуально, но сохранён в доступном дереве с `role="status"`, `aria-live="polite"` и `aria-atomic="true"`.

Иллюстрация не изменялась и не переименовывалась. Прозрачность, квадратные пропорции и статический импорт Next Image сохранены. Максимальный размер — 264 px в двухколоночной композиции и 148 px в вертикальной. Изображение не обрезается. Оно показывается только для ошибок соединения и временной недоступности сервиса; остальные состояния оформлены нейтрально.

Вертикальная композиция включается, когда внутренняя ширина компонента не превышает 540 px. CSS container query учитывает также ситуацию с боковой панелью каталога на планшете. На телефоне кнопка занимает ширину текстового блока; высота кнопки — не менее 52 px. Повтор не меняет размеры блока и кнопки.

Сохранены переходы кнопки и вращение значка только во время запроса. При `prefers-reduced-motion: reduce` вращение, переход и масштабирование при нажатии отключены. Постоянных декоративных анимаций нет.

## Сохранение поведения

Транспорт, API-контракты, классификация ошибок и обработчики повтора не менялись. Сохраняются тайм-ауты, отмена запросов, защита от параллельных попыток, фильтры, сортировка, текущая страница и восстановление каталога без перезагрузки документа. Пустой каталог остаётся отдельным состоянием.

Пояснение о возможных перебоях и тематическая иллюстрация используются только для `connection`: сетевых ошибок, тайм-аутов и HTTP 408/502/503/504 согласно существующей классификации. HTTP 500, HTTP 429 и остальные ошибки имеют собственные нейтральные переводы.

Бэкенд, исходное изображение, `api-errors.ts`, `lib/api.ts`, `lib/catalog-errors.ts`, зависимости и lockfile не изменялись.

## Ограничения

Проверяется локальный production-экспорт с синтетическими данными и имитацией отказов API. Реальный бэкенд не отключался и не изменялся. Причина реального сбоя технически не определяется.

Системный Node.js 20 не поддерживает используемый проектом `--experimental-strip-types`; проверки выполнены существующим Node.js 22.20.0 из `/tmp`. Полные тесты и браузерная сборка требуют запуска вне песочницы из-за ограничений дочерних процессов, локального сервера и Chromium.

ESLint в проекте не настроен: `pnpm --filter storefront lint` запрашивает первоначальную конфигурацию и завершается без проверки. Новые зависимости и конфигурация линтера в рамках этой задачи не добавлялись.

Safari, Firefox, физические мобильные устройства и ручное прослушивание экранным диктором не проверялись. Адаптивность использует CSS container queries; старые браузеры без их поддержки отдельно не проверялись.
