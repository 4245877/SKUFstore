SKUFstore — карта проекта

package.json / pnpm-workspace.yaml / pnpm-lock.yaml
  pnpm workspace; активный пакет apps/storefront. Node 22 используется в CI.

apps/storefront/src/app/
  Next.js маршруты: (uk) — украинские URL без префикса; (en)/en — английские URL.
  sitemap.ts / robots.ts — публикация SEO-маршрутов.

apps/storefront/src/views/
  Общие страницы магазина, профиля, авторизации и справочных разделов.
  Локализованные маршруты передают locale в эти страницы.

apps/storefront/src/components/
  Общие компоненты, Header/Footer, доступность каталога и аналитика.

apps/storefront/src/i18n/
  UI-словари UK/EN, правила локализованных ссылок и публикации переводов товара.
  DE зарезервирован; немецкие маршруты не опубликованы.

apps/storefront/src/lib/
  API-клиент SKUFnya, снимок каталога для статического экспорта, SEO,
  хранение корзины/избранного и черновика checkout, серверные котировки.
  demo-store.ts используется действующими страницами и тестами.

apps/storefront/scripts/catalog-freshness.mjs
  Сверка публичного API и опубликованных Pages; вызывается GitHub Actions.

apps/storefront/test/
  Unit-тесты и браузерные регрессии. Имена stage1/stage2/stage2b обозначают
  происхождение сценариев; verify-stage1-export, browser-stage2 и синтетическая
  stage2b-сборка остаются частью CI.

apps/storefront/next.config.ts / Dockerfile
  DEPLOY_TARGET=pages — статический export для GitHub Pages.
  DEPLOY_TARGET=server — standalone-вариант; его актуальность требует проверки
  перед удалением. Google Fonts загружаются на этапе сборки через next/font.

.github/workflows/deploy-storefront.yml
  Unit-тесты, typecheck, fixture-сборка, production-сборка, проверки экспорта,
  Pages deploy и проверка актуальности каталога; расписание запускает reconcile.

packages/shared-types/
  Историческая копия DTO; сейчас не входит в workspace и не импортируется,
  но package.json явно копируется Dockerfile. Сохранена до проверки server build.

docs/
  Отчёты реализации i18n и доступности каталога, инструкции воспроизведения
  проверок и связанные доказательства/скриншоты. Датированные baseline и
  production-сведения описывают момент проверки, а не текущее окружение.

Не версионируются: node_modules/, .next/, out/, *.tsbuildinfo, .env*.
Файлы .env, production, пользовательские данные и резервные копии не являются
артефактами очистки исходников.
